# Exports de conversa

Ao fim de cada sessão de trabalho no Claude Code, rode `/export` e salve aqui como `AAAA-MM-DD-claude-code-<tema>.txt`. O `/export` grava a conversa em texto puro.

Antes de versionar, procure e cubra:
- e-mail;
- nome da organização;
- caminhos de pastas da empresa;
- IDs de sessão;
- chaves.

Registre o que foi coberto.
